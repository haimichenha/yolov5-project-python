# YOLOv5 识别快捷包使用说明

这是一个基于教学提供文件继续整理的 YOLOv5 训练快捷包。原始实现通过若干 Python 脚本把图片、Labelme 标注 JSON 与 YOLO TXT 标签串联起来，便于完成数据集制作、训练集/验证集划分和权重测试。

> 这是一次初步训练的使用包，并非经过系统调参的完整工程；原始记录仅说明其识别效果一般，未保留可复核的 Precision、Recall 或 mAP 数值。

## 获取完整文件

完整使用包位于 `team.rar`，并通过 Git LFS 管理。克隆仓库后执行：

```bash
git lfs pull
```

下载完成后再解压使用。批量重命名图片可使用其他常规工具完成。

## 使用前说明

- `dataset.py` 与 `train.py` 不建议在不了解 YOLOv5 训练流程时大幅修改；原始使用包仅对 `train.py` 的局部配置做过调整。
- 使用自己的权重时，应配套使用对应的数据集 YAML，并确认其中的 `nc`（类别数量）正确。
- 数据集路径、类别数量与脚本生成的 YAML 内容必须逐项核对；不要直接沿用原始电脑上的绝对路径。

## 数据准备与标签转换

1. 将待训练图片放入 `dataset/train`。
2. 使用 Labelme 框选目标并保存 JSON。Labelme 默认会将 JSON 与图片放在一起，随后将 JSON 移动到 `dataset/json`；可将备份材料放入 `zhunbei`。
3. 运行 `boat.py`，将 JSON 转换为 YOLO 格式的 TXT 标签。转换后的文本会放入 `txtrds`。
4. 确认图片数量、标签数量和文件名一一对应；同名图片必须有同名 TXT 标签。

## 训练集与验证集整理

1. 运行 `imageManger.py`，按比例从 `train` 中随机复制图片到 `val`。
2. 运行 `latroYun.py`：脚本会处理中转目录 `dataset/txtManager`，并将匹配到的 TXT 标签复制到训练集、验证集对应的 `labels` 目录；无法匹配的图片或标签会被移入名称明确的单独目录。
3. 检查脚本生成的 YAML：训练/验证路径与 `nc` 必须与本次数据集一致。
4. 如需为文本目录补齐 `labels`，再使用 `fanlabel.py` 处理。

## 训练与检测

原始记录使用过 `v5lite-c.pt`，并在 **450 epochs 以上** 完成过训练。训练轮数是一次训练任务内的设置，不是重复启动 `train.py` 的次数；若要改善检测效果，应优先补充样本并使标注框尽量贴合目标。

训练时，确认权重与 YAML 配套、`nc` 正确后再启动 `train.py`。原始配置使用 GPU `"0"`，可按本机环境调整。

训练结束后使用 `tryDetect.py` 验证权重效果，并将脚本中的权重路径指向 `runs` 下的实际输出。`pipi` 目录用于导出给树莓派使用的文件。
